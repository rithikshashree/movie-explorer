# 🎬 Movie Explorer

## Project Description

Movie Explorer is a React application that allows users to search for movies using a public movie API. Users can search movies, view movie details, check IMDb ratings, and browse different movie categories.

## Features

- Search Movies
- View Movie Details
- Display IMDb Ratings
- Category Filters
- Responsive Design
- Loading Indicator
- Error Handling

## Technologies Used

- React
- JavaScript
- React Router DOM
- CSS
- OMDb API

## Installation

```bash
npm install
npm run dev
```
